## 💡 Sobre mí

Soy estudiante del 6to ciclo de **Ingeniería en Sistemas** y egresado de Desarrollo de Sistemas. Mi enfoque profesional se centra en el cruce entre la ingeniería de software, el análisis de datos y la automatización, con el objetivo de generar impacto real en el negocio. Me apasiona integrar tecnologías modernas e **Inteligencia Artificial** para optimizar flujos operativos.

- 📊 **Especialidad:** Extracción, análisis y visualización de datos para la toma de decisiones.
- ⚙️ **Enfoque:** Arquitecturas limpias, automatización de tareas repetitivas y optimización continua.
- 🤖 **Intereses:** Desarrollo web interactivo (React/Node), integración de APIs de IA y diseño de bases de datos robustas.
- 🎯 **Filosofía:** La tecnología es la herramienta; resolver problemas de negocio de forma eficiente es la meta.
